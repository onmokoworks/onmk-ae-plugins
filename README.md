# onmk AE Plugins

After Effects plugins developed and maintained by onmk.

## Repository layout

- `plugins/` — individual After Effects plugins
- `crates/` — shared Rust crates
- `tools/` — shared build and development tools
- `templates/` — reusable plugin templates

Experimental and unpublished work is developed outside this repository and moved here when it is ready for continued development or publication.

## Status

Repository structure is being prepared. Plugins will be migrated here incrementally with their existing Git history preserved.
