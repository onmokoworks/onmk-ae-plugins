## Limits

These are AEXCompat and pure CPU tests, not Adobe AE validation. AE UI, live project cache invalidation, animated parameters, render queue and macOS are untested. GPU is not implemented or advertised. Distances cover the layer's own dimensions; arbitrary upstream layer-bound expansion is not established. Gaussian blur is separable CPU convolution and large radii can be expensive. Original OLM pixel equivalence is not claimed.

Earlier `dist/validation/` and `dist/validation-20261021-173730/` are preliminary evidence for older builds; only the final hash and paths above describe the delivered artifact. The first far-field assertion accidentally sampled within 13 px of the low-alpha sentinel; the test point was moved to the opposite, genuinely unaffected corner. No production behavior was altered to satisfy that assertion.
