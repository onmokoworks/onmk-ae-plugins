# Rio Grade 検証・対応範囲

概要とビルド手順は[README.md](README.md)を参照してください。

現行実装は8bit・CPUのClassic Renderです。16/32bit、Smart Render、GPU対応は宣言していません。同梱シェーダーは未使用の雛形です。

色補正前にRGBの事前乗算を解除し、補正後に元のアルファで事前乗算して合成します。アルファ自体は変更せず、Strength 0では入力をバイト単位で保持します。

回帰テストでは不透明画像の補正結果と半透明画像の結果を比較します。AEXCompatでは透明RGBと半透明入力のStrength 0／50／100も検査します。全画面テストだけでは、部分領域の描画、同一インスタンスの寿命、メモリ上限までは保証しません。

行コピーは全行の範囲を確認してから書き込み、パディングを保持します。短いバッファ、桁あふれ、逆順の行を単体テストしています。出力寸法が合わない場合は、一部だけ描画して成功扱いにせずエラーを返します。これは部分領域描画への対応ではありません。入力用メモリの確保失敗は返せます。色補正はそのARGB8バッファを直接更新し、画像全体の追加コピーを省きます。1920×1080では8,294,400バイト分の作業領域を削減します。ホスト側や同時レンダリングを含むメモリ上限は未実装です。
