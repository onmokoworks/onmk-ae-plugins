# ONMK TaperStroke

同じレイヤーの開いた Mask Path を中心線にして、終点に向かって細くなるストロークを透明背景に描画する AE エフェクトです。元のマスクは変更しません。

## 使い方

1. `build.ps1` で Windows x64 用 `dist/ONMK_TaperStroke.aex` をビルドします。
2. AEX を AE の Plug-ins フォルダへ配置し、AE を再起動します。
3. 平面などに開いたマスクを描き、マスクモードを「なし」にします。
4. ONMK カテゴリの TaperStroke を適用し、Path でマスクを選びます。

| パラメータ | 意味 |
|---|---|
| Path | 同一レイヤーのマスク。初期値は最初のマスク |
| Width | 元のレイヤー座標での線幅、0–2000 px |
| Taper Start | テーパー開始位置。元のパス全長に対する 0–100% |
| End Width | 終点の線幅。Width に対する 0–100% |
| Taper Ease | 0.1–10。1 は直線的な幅変化。値を大きくすると細くなる位置が後ろへ移動 |
| Cap | Round / Flat。0幅の終点はどちらも尖る |
| Color | 線色 |
| Opacity | 0–100% |
| Trim Start | 元のパスの開始位置、0–100% |
| Trim End | 元のパスの終了位置、0–100% |

数値パラメータは AE 標準のキーフレームに対応。Taper Start=100% は全長一定幅です。未選択・削除済み・閉じたパス・長さ0のパスは透明を返します。描画はレイヤーの範囲内にクリップされます。

Trim Start ≥ Trim End は透明です。v0.3 の Trim は元のパス上の太さを維持したまま切り出し、切り口に指定した線端を付けます。Trim を動かしてもテーパーの開始位置・進み方は伸縮しません。既存10パラメータのIDと保存値は維持しています。v0.2 からの変更により、以前の Trim 付きプロジェクトの見た目は変わります。

Round は各位置の半径を持つ円を連続的に動かした外周として描き、側面と線端を共通接線で滑らかにつなぎます。幅の変化が急なときは、従来の法線方向へずらした輪郭より膨らむ場合があります。非常に短い区間では大きい円が小さい円を内包し、円状の形になります。Round は切り口の外側へ半径分伸びます。Flat は切り口で止まります。

位置と幅の誤差を制限して冗長な点を削減し、各走査線ではY範囲が重なるポリゴンだけを処理します。円の被覆率は円・楕円の式から計算し、拡大時の線端の多角形化を避けています。

## 実装と検証

PF PathQuery / PathData Suite からレンダー時刻のパスを読み取り、AE の弧長評価でベジェのハンドルを反映します。0.5 px 以下の間隔でサンプリングし、累積距離から幅を求め、法線方向に輪郭を生成します。ポリゴンの和集合を走査線でラスタライズし、垂直4サンプルと水平の被覆率でアンチエイリアスをかけます。v0.3.1 の出力はストレートアルファの ARGB（RGB は線色を保持し、被覆率と不透明度はアルファだけに適用）、8/16/32 bpc、通常 Render と SmartRender に対応しています。

`cargo test --locked` で描画コアを検証できます。`cargo run --release --example preview -- preview.ppm` は同じ描画コアによる曲線のサンプルです。これは AE 実機レンダーの証拠ではありません。極端に鋭い折れやカスプは長い突起を避けるため丸い結合に切り替えます。GPU 描画は実装していません。

パスAPIの仕様: [After Effects SDK: Working With Paths](https://ae-plugins.docsforadobe.dev/effect-details/working-with-paths/)

ホスト側の検証状況は `VALIDATION.md` を参照してください。

`ae-demo.jsx` はインストール後の AE で実行するテストコンポ作成スクリプトです。3種類の線端と、マスク形状・線幅のキーフレームを追加します。

Windows の PiPL は文字コード変換による破損を避けるためバイナリファイルとして埋め込みます。`python verify_pipl.py`（`pefile` が必要）で、リンク後の AEX 内資源が生成元と一致するか検証できます。
