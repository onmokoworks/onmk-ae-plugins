# TuiImage MVP Spec

## Goal

Render an After Effects layer/frame into a TUI-like raster effect using a
constrained set of character systems and output modes.

The MVP is successful when the effect can be applied to footage or a precomp,
scrubbed in AE, and previewed as intentional terminal-native imagery, not merely
an image with random letters laid on top of it.

## Product Scope

### MVP

- Native AE effect: `TuiImage`.
- Rust implementation using the local Rust AE plug-in pattern.
- GPU render path using `wgpu` compute shader.
- CPU fallback using the same sampling/glyph model.
- Preset-driven block/Braille/TUI-gradient raster output.
- Controls suitable for keyframing inside AE.

### Later

- Full comp-to-comp generated AE layer reconstruction.
- CEP/UXP companion panel for batch export and preset editing.
- APNG/PNG-sequence export helpers.
- ANSI escape export / terminal playback.
- Batch renderer for many comps.

## Inputs

Required:

- Source layer pixels from AE render input.
- Preset: `ascii-classic`, `block`, `braille`, or `tui-gradient`.
- Cell width and height.

Adjustable controls:

- `contrast`: contrast multiplier before glyph mapping.
- `gamma`: luma shaping before glyph mapping.
- `edgeBoost`: edge magnitude contribution.
- `invert`: invert luma before mapping.
- `colorMode`: `mono`, `source`, `gradient`.
- `sourceMix`: mix generated result back toward source.

## Outputs

Priority order for the native effect:

1. `ae-raster-frame`
   - The live effect output returned to AE.
   - First target, because it proves the renderer in the real host.
2. `cpu-fallback-frame`
   - Same visual model, slower but reliable.

Later companion outputs:

1. `raster-sequence`
   - PNG sequence generated from glyph grid.
2. `apng`
   - Compact preview output for web/404 use.
3. `plain-text`
   - UTF-8 text dump for current frame.
4. `ansi-text`
   - Text + ANSI truecolor escape sequences.
5. `ae-text-layers`
   - One text layer or a small number of grouped text layers.
   - Not recommended for long sequences in MVP.

## Presets

### ascii-classic

Ramp:

```text
 .:-=+*#%@
```

Use for rough terminal nostalgia. It has the weakest density but the strongest
recognition as "ASCII art".

### block

Glyph family:

```text
 ░▒▓█▀▄▌▐
```

Use as the first serious image preset. It gives strong silhouettes, smooth-ish
gradients, and relatively simple rasterization.

### braille

Glyph family:

```text
⠀⠁⠃⠇⡇⣇⣧⣿
```

Use for high apparent resolution. Braille is more complex because each character
represents a 2x4 sub-cell matrix, but it can look much sharper than ASCII.

### tui-gradient

Composite preset:

- block/half-block glyphs
- source-derived luma
- terminal-style palette ramps
- optional edge layer blended into brightness

Use for the modern "pretty terminal dashboard" look.

## Rendering Pipeline

1. Export or load source frame.
2. Convert to linear-ish working RGB and luma.
3. Optional edge pass: Sobel or Scharr magnitude.
4. Divide frame into cells.
5. For each cell, compute average luma, variance, edge score, and average color.
6. Choose glyph from preset.
7. Choose foreground/background color.
8. Rasterize glyph grid into the AE output frame.

## Runtime Choice

Recommended first build:

- Rust AE effect using `after-effects` crate.
- PiPL generated by `pipl` build dependency.
- `SmartRender` and `SmartRenderGpu` commands wired from the beginning.
- `wgpu` compute shader for the main path.
- CPU fallback for stability and testability.

Do not build this first as a CEP-only exporter. That would prove a nice tool,
but not the plug-in the user actually wants. Slightly inconvenient distinction,
but useful ones often are.

## Non-Goals for MVP

- Exact terminal emulator simulation.
- Huge AE text-layer generation for every frame.
- Semantic parsing of source layers.
- Recreating a full TUI widget system inside AE.
- GPU font rendering with arbitrary system fonts.

## Milestones

1. Spec + preset contract.
2. Rust AE effect scaffold following `ColorfulEchoRust`.
3. CPU block-mode renderer for one AE frame.
4. `wgpu` block-mode compute renderer following `OpticalFlareRust`.
5. Braille mode.
6. TUI-gradient color mode.
7. Preset JSON embedding/loading.
8. Optional CEP/UXP companion for APNG/text/batch export.
