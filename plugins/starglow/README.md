# ONMK Starglow

ONMK Starglowは、Adobe After Effects向けの実験的なスペクトル・スターグローエフェクトです。

複数方向の光条、色マップ、しきい値、グロー合成、CPU／GPUレンダリング経路を備えています。

- 表示名: `ONMK_Starglow`
- After Effects Match Name: `ONMK_Starglow`
- 状態: 実験的

## Build

```powershell
cargo build --release
```

## English

ONMK Starglow is an experimental spectral star-glow effect for Adobe After Effects, with multi-direction rays, color maps, threshold controls, glow compositing, and CPU/GPU render paths.
