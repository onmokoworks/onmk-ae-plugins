# LLM-assisted documentation notice

Some documents in this directory were drafted, reorganized, or edited with assistance from large language model tools.

These files should be treated as project notes and planning material, not as a substitute for source code, build scripts, runtime behavior, or manual verification in After Effects.

## Scope

This notice applies to documentation and planning files under `docs/`, including design notes, implementation notes, release notes, and status summaries.

It does not imply that binary release artifacts, source code, or build outputs were generated entirely by an LLM.

## Review policy

Before relying on these documents for implementation or release work:

- check the current source code and scripts;
- verify behavior in After Effects when relevant;
- treat command examples and environment notes as project-maintained instructions, not external authority;
- update the documentation when observed behavior differs from the notes.
